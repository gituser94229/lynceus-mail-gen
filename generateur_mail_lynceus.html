🔑 Clé API Claude requise

Pour que l'IA extraie les infos de la fiche, il faut une clé API Anthropic. Va sur console.anthropic.com (créer un compte si besoin), clique sur "Create Key", copie-la et colle-la ci-dessous.

La clé est stockée uniquement dans ton navigateur (localStorage). Aucun envoi ailleurs que vers l'API Anthropic.

📈 Clé API Twelve Data (cours de bourse)

Pour récupérer automatiquement les cours de clôture, il faut une clé API Twelve Data (gratuit, 800 appels/jour, pas de CB). Va sur twelvedata.com/account → inscription gratuite → API Keys → copie-la et colle-la ci-dessous.

La clé est stockée uniquement dans ton navigateur (localStorage). Si tu annules, tu pourras toujours saisir les cours manuellement.
